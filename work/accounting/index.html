Prototype

Accounting firm

Documents in, a draft return out

The firm wanted what every firm wants: client documents go in, and a return comes out ready for a partner to review. We’re building it, with every number on the return traced back to the page it came from.

Preparing a return means chasing the client for documents, keying in figures from W-2s, 1099s, and K-1s, and checking the result against the paperwork. The firm had tried the usual software and still ended up retyping. And speed sets the price: a firm that finishes a return in thirty minutes can undercut one that takes four hours.

The platform starts from last year’s return to list the documents each client should send, and shows what’s still missing. It reads every upload, splits a combined brokerage statement into one document per form, and records each figure with the page it came from. It catches duplicates, rescans, and forms made out to someone else. Bank statements become categorized transactions, with missing months, duplicates, and unusual items flagged.

From there it prepares the draft and checks it: amounts that don’t match a source document, documents with nothing reported, and income in the wrong category. Code does all the arithmetic, never the AI. Every number links back to its source, and nothing is marked ready until a named reviewer and a partner sign off.
