Home care agency

Case acceptance in seconds

Health plans and hospitals post open home care cases to a referral portal, and many go to whichever agency accepts first. Other agencies had software accepting in seconds. We built this agency its own, run by its own rules, over a weekend.

Each open case on the portal comes with a zip code, a language, a pay rate, a contract, and a payer. Staff used to open each one and decide whether to take it. By the time they had, another agency’s software usually had.

Now the system checks the portal every five seconds, and can go as fast as twice a second. It reads each new case and applies the agency’s own rules: which boroughs and zip codes, which languages, which rates and contracts. Cases sent to every agency and cases sent only to this one can follow different rules. It accepts the cases that fit, assigns each to the right office, declines the rest with the proper reason, and logs every decision.

Staff change the rules, working hours, and mode from a control panel, with no developer involved. It runs in the agency’s own cloud account and alerts the team if it ever stops. We built the core so it can be pointed at the agency’s other referral portals next.
